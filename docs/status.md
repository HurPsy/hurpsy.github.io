# Status and directions

This page says what HurPsy can do today and where it is heading. It is updated as the work moves on.

## Working today

- **HurPsyDesign** designs complete experiments: stimuli, locators, sets, modifiers, block, trial and step patterns, and responses. It previews them on the full screen at their true size, builds sessions and saves them.
- **HurPsySession** opens saved sessions and draws the pictures of each run.
- **HurPsyRun** runs a session's steps with exact frame timing and records the responses.
- **A set of sample experiments**, from simple visual search tasks to a Stroop test, is used to test every part of the model.

## Next steps

- Joining HurPsySession and HurPsyRun so that a whole run, with its results file, happens from one place.
- Checks that a session must pass before it may be run.
- Questionnaire screens, such as consent and demographic forms, shown inside a session.
- English tutorial pages on each building block, and Turkish tutorial videos for the first testers.

## Further on

- Backgrounds chosen for each step.
- Stimuli that switch on and off during a step.
- A simulated participant, for seeing what the result files would and would not tell a researcher before real data is collected.
